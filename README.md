# Лабораторная работа №7: Работа с базой данных (SQLite) и CRUD-операции

**Тема:** Заметки с тегами (множественные теги)  
**Вариант:** 16  
**Технологический стек:** Node.js, Express.js, SQLite (better-sqlite3)

---

## 1. Цель работы
Изучение основ работы с реляционными базами данных, выполнение CRUD-операций (Create, Read, Update, Delete) и их интеграция с веб-фреймворком Express.

## 2. Постановка задачи
Разработать REST API для управления заметками (сущность `notes`) со следующими требованиями:
- **Модель данных:** `id` (целочисленный, первичный ключ), `title` (строка), `body` (текст), `tags` (JSON-массив строк).
- **Маршруты:**
  - `GET /api/notes` — получение списка всех заметок.
  - `POST /api/notes` — создание новой заметки.
  - `PUT /api/notes/:id` — обновление существующей заметки.
  - `DELETE /api/notes/:id` — удаление заметки.
- **Фильтрация:** поддержка query-параметра `?tag=js` для поиска заметок по конкретному тегу.
- **Валидация:** 
  - Поле `title` не может быть пустым (возврат ошибки `400 Bad Request`).
  - Поле `tags` должно быть валидным JSON-массивом строк.
